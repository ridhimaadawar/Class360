# 🎓 Class360 – Student Portal & Academic Manager

**Class360** is a modern academic portal designed to unify the student and faculty experience by integrating academic and extracurricular management into a single platform. Developed as a **minor project** during my MCA at **BCIIT (IPU)**, it addresses the key gaps in traditional student management systems.

---

## 🌟 Key Features

- 🧑‍🎓 Personalized student dashboard  
- 📝 Assignment posting and submission  
- 📢 Centralized notifications and announcements  
- 📈 Academic progress analytics (grades, attendance, deadlines)  
- 📅 Task and deadline reminders  
- 🧠 Faculty portal to manage student data  
- 🗨️ Peer-to-peer chat modules and chatbot (planned)  
- 🔒 Unique Student ID System for tracking

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap  
- **Backend:** Python, Flask *(optional: Django)*  
- **Database:** MySQL or PostgreSQL  
- **Other Tools:** Git, GitHub, Selenium (testing), Postman (API)

---

## 💻 Modules Overview

- **Student Dashboard** – View grades, attendance, schedules, assignments, and notifications  
- **Faculty Dashboard** – Post assignments, view submissions, send announcements  
- **Analytics Module** – Real-time progress charts and class-level performance insights  
- **Task Manager** – Auto-reminders for submissions, exams, events  
- **Login System** – Role-based access (student/faculty/admin)
